# Urleso.Api.Client

C# client for the Urleso API, generated by NSwag from the OpenAPI document ([`swagger.json`](swagger.json)).

`Client.g.cs` and `Contracts.g.cs` are generated code — never edit them by hand.

## How to update the client after an API change

1. In the [Urleso repository](https://github.com/exqzmepls/Urleso), regenerate the OpenAPI document:

    ```shell
    dotnet build src/Urleso.Api -c Release -p:OpenApiGen=True
    ```

2. Copy the resulting `src/Urleso.Api/swagger.json` into this directory (replacing the existing `swagger.json`)
3. Regenerate the client code:

    ```shell
    dotnet build src/Urleso.Api.Client -c Release -p:ClientGen=True
    ```

Generated client code will appear in this project (`Client.g.cs`, `Contracts.g.cs`).
