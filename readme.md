# Urleso Web

Web UI for [Urleso](https://github.com/exqzmepls/Urleso) — a simple URL shortener.

Standalone Blazor WebAssembly app (MudBlazor) served as static files by nginx in Docker. The browser calls the Urleso API directly.

## How to run locally

_The Urleso API must be running and allow this app's origin via CORS (see `CORS_ALLOWED_ORIGINS` in the Urleso repository)._

```shell
dotnet run --project src/Urleso.Web
```

The API base address for local development is set in [`src/Urleso.Web/wwwroot/appsettings.json`](src/Urleso.Web/wwwroot/appsettings.json) (`http://localhost:6800/` by default).

## Docker

```shell
docker build -t urleso.web:latest .
```

The container serves the app with nginx on port `8080` and requires the `API_BASE_ADDRESS` environment variable — at startup it regenerates `appsettings.json` from it:

```shell
docker run -p 6080:8080 -e API_BASE_ADDRESS=http://localhost:6800/ urleso.web:latest
```

The full Urleso stack (API, redirect service, database and this web app) is composed in the [Urleso repository](https://github.com/exqzmepls/Urleso) — its `docker compose` uses the `urleso.web:latest` image built here.

## API client

[`src/Urleso.Api.Client`](src/Urleso.Api.Client) is generated by NSwag from the vendored OpenAPI document ([`swagger.json`](src/Urleso.Api.Client/swagger.json)). See its [readme](src/Urleso.Api.Client/readme.md) for how to update the client after an API change.
